## Question and competing hypotheses

For actual affine curve records y_i^2=x_i^3+a*x_i+b, let
N=u^2-(X^3+a*X+b)*v^2. An interpolation row u(x_i)+y_i*v(x_i)=0
implies N(x_i)=0. A pure u nodal witness can vanish at paired curve points and
is not by itself a useful relation. Test whether a tight pole-degree budget
eliminates that padding before optimizing the colored search.

H1: for any nonzero pair (u,v), the odd-degree cubic makes N nonzero. If t
selected x's are distinct, all selected equations hold and natDegree N<=t,
then N has exactly those t simple roots. In particular v(x_i)!=0, so the
selected y_i is recovered uniquely by -u(x_i)/v(x_i). This is a useful
polynomial certificate; the divisor-to-group-sum theorem is separate.

H0/control: a pure nodal row (g,0) has norm g^2 and degree2t, so it cannot
pass the tight degree<=t test for t>0. Dropping distinct x's or the degree
budget permits repeated-root padding. Empty support can retain constants.

H2/search limitation: finding a tight nonzero colored interpolation row can
still cost exponentially many choices. The certificate does not supply a
fast extractor, useful original yield or a subexponential ECDLP algorithm.
The previous exact-kernel injectivity argument applies when t<=dU; its pure
u witness does not establish the same barrier in the tight useful regime.
